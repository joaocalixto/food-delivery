# Caderno MCP

Material da aula de MCP no `restaurant-service`, num arquivo só: `caderno-mcp.html`.
Abra no navegador (duplo clique no arquivo, ou baixe pelo GitHub com **Download raw file**).

Tem um índice na esquerda com:

- plano da aula (90 min) e checklist da véspera;
- MCP em palavras simples, com diagramas;
- como construir e rodar o MCP (`restaurant-service/MCP.md` tem a versão curta);
- os 5 restaurantes de teste, o `DataSeeder` e como recarregar os dados;
- perguntas para testar a IA, com a resposta esperada de cada uma;
- MCP × REST, exercícios, produção, armadilhas e links.

O código do caderno é o mesmo que está no repo: `restaurant-service/.../mcp/RestaurantMcpTools.java`
e `restaurant-service/.../config/DataSeeder.java`.
